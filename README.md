# MyEmployee

A web application for managing employee data.

## Technologies Used

- **Back-end**: Python Django DRF
- **Front-end**: HTML/CSS
- **Database**: SQLite3

## Prerequisites

Before running the project, make sure you have the following installed:

- Python 3.x
- Pip (Python package installer)

### Required Packages

In your terminal or CMD, navigate to the project directory and install the following packages

```bash
# Install Django
pip install django

# Install Django Rest Framework (DRF)
pip install djangorestframework

# Install Pillow for handling image files
pip install Pillow
```

### Database Migrations & Running the Server

Run the following commands to create and apply database migrations

```bash
# Make migrations
python manage.py makemigrations

# Apply migrations
python manage.py migrate
```

After setting up the database, start the Django server

```bash
python manage.py runserver
```
